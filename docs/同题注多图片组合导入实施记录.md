# 同题注多图片组合导入实施记录

更新时间：2026-07-08

## 背景

部分 Word 文档会在同一段落内放置多张图片，并在下一段只提供一个图题注，例如“图A-6-6”。这类结构表示一个题注说明一组图片，不应按“题注重复”处理。

## 实现规则

- DOCX 导入解析图片时，先按段落收集该段内的全部图片关系 ID。
- 如果同一段落内多张图片共用同一个后续图题注，则横向拼接为一张白底 PNG 组合图片。
- 组合图片继续使用原题注和原图号，例如 `图A-6-6`。
- 导入预览提示调整为 `IMPORT_IMAGE_CAPTION_SHARED`：同一图题注关联多张图片，已按组合图片导入。
- 只有不同图片组或不同段落重复使用同一个图题注时，才继续提示 `IMPORT_IMAGE_CAPTION_DUPLICATE`。
- 结果记录中的 `图A-x-y` 引用仍映射到一个 `[[FIG:import:A-x-y]]` 临时 token，确认导入后再转为真实项目图片 ID。

## 验证

- 新增导入媒体解析单测，覆盖同一段落两张图片共用一个题注时只生成一条证据图片记录。
- 使用现有导入源 `storage/imports/15/source.docx` 验证：
  - `图A-6-6`、`图A-6-7`、`图A-7-4` 均识别为同题注组合图片。
  - `IMPORT_IMAGE_CAPTION_DUPLICATE` 数量为 0。
  - 组合图片提示数量为 3。
