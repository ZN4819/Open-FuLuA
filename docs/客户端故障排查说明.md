# 客户端故障排查说明

## 客户端打不开

1. 先关闭重复打开的“附录A编写工具”。客户端只允许一个实例运行。
2. 再次打开客户端，等待本机服务完成恢复检查。
3. 如果出现诊断页，依次尝试“重试”和“打开日志目录”。复制诊断信息时不要附带项目正文或证据图片。
4. 仍无法打开时，保留日志和数据目录，联系维护人员；不要删除数据目录，也不要反复覆盖安装。

## 提示上次未正常关闭

客户端会先检查数据库完整性，再决定是否进入项目页面。这不是数据丢失提示。若完整性检查失败，请查看日志并从客户端提供的最近备份中恢复；不要手工替换正在使用的数据库文件。

## 项目或图片找不到

- 确认使用的是同一个 Windows 账户。
- 在客户端中检查项目列表和图片题注，不要直接改动数据目录中的文件名。
- 如果刚完成迁移，先按提示重启客户端。
- 若恢复备份，请先保留当前快照；客户端恢复流程会在替换数据前自动创建恢复前备份。

## DOCX 导入或导出失败

- 导入时请选择本工具导出的 editable/final DOCX；受保护、损坏或结构差异过大的文档可能无法自动导入。
- 导出前先运行项目校验，处理错误项后重试。
- 确认磁盘仍有可用空间，并关闭正在占用同名 DOCX 的 Word 窗口。
- 失败后保留日志；不要删除项目来“重试导出”。

## 更新没有安装

保存、导入、导出、迁移或恢复进行中时，客户端会延后更新。更新下载完成后仍需用户确认退出。备份失败、校验失败或本机服务无法安全停止时，更新不会继续，这是数据保护行为。

## 如何恢复备份

在客户端菜单选择“数据 → 从备份恢复…”，核对备份时间后确认。恢复过程中不要结束客户端。恢复完成后客户端会重新启动本机服务；若恢复失败，请保留日志和现场，不要删除失败标记或备份目录。

## 卸载与重装

正常卸载只删除程序，不删除项目、图片、导出记录、日志或备份。重装后应继续看到原有项目。准备彻底清除数据前，请先导出需要保留的 DOCX 并备份数据；不要把“卸载程序”当作数据清理工具。

## 提交问题时提供什么

- 客户端版本和 Windows 版本。
- 问题发生前的最后一个操作。
- 诊断页文字和日志文件。
- 是否发生异常关机、磁盘空间不足、杀毒软件拦截或手工移动数据目录。

不要在公开问题中上传项目正文、证据图片、完整数据库或内部访问凭据。
