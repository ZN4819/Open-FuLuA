# Windows 客户端安装与卸载说明

## 适用范围

本测试安装包适用于 Windows 10 和 Windows 11 的 64 位系统。安装包尚未进行代码签名；如 Windows 显示发布者或安全提示，请确认安装包来源后再继续。当前测试包使用默认图标，属于临时资源，不代表正式品牌图标。

## 安装

1. 运行提供的 Setup 安装包。
2. 安装包会自动按当前用户范围安装，无需管理员权限。
3. 按提示确认安装位置后完成安装。
4. 通过开始菜单或桌面快捷方式打开“附录A编写工具”。

## 首次使用与数据迁移

首次打开时，可选择新建空数据或迁移旧版数据。选择迁移后，按界面提示选择旧版数据目录；旧版目录不会被修改。

## 卸载

可在 Windows 的“已安装的应用”中选择“附录A编写工具”并卸载，也可运行安装目录中的卸载程序。

卸载只移除程序文件，项目数据会保留在当前用户的本地数据目录中。重新安装后，之前的项目仍可继续使用。

## 测试包限制

这是功能验证用的未签名测试包，不包含自动更新功能。当前已完成本机临时用户目录验收，但干净 Windows 用户/VM 验收待执行。建议在正式业务环境部署前保留原始数据备份。
