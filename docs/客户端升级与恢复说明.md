# 客户端升级与恢复说明

## 检查更新

Windows 安装版会定期检查新版本；也可以在“帮助 → 检查更新”中手动检查。便携开发版本不会连接更新服务。

发现新版本时，客户端会等到数据保存和维护操作结束后再下载。下载完成后会询问是否退出并安装；选择“稍后”会继续保留当前版本和当前工作，不会停止本地服务。

确认安装后，客户端会先保存一份“升级前备份”。只有备份成功且本地服务确认停止后才会退出并安装。任何一步失败都会取消本次安装，并保留当前版本供继续使用。

## 异常关闭后的选择

如果上次没有正常关闭，客户端会在打开项目页面前检查本地数据库：

- 检查正常时，可以继续打开、查看日志或恢复备份。
- 检查异常时，不会提供继续写入入口，只能查看日志或恢复备份。

日志目录中只记录诊断信息，不包含项目正文。向支持人员提供日志前，仍建议先确认其中没有您不希望共享的本机路径信息。

## 升级失败后的恢复

如果新版本无法启动或数据库检查未通过，客户端会保留升级前备份。选择恢复后，客户端会先停止本地服务，再恢复升级前备份并重新启动。

恢复失败时不会显示为成功，也不会删除待恢复标记。请保留当前数据目录和日志，避免手工移动、覆盖或删除其中的数据库、`backups` 和 `recovery` 目录。

## 更新范围与限制

- 支持 Windows 10/11 x64 安装版。
- 数据默认保存在 `%LOCALAPPDATA%\附录A编写工具`，与安装目录分离；升级和卸载不会主动删除该目录。
- 更新包由更新元数据中的 SHA-512 校验保护。校验失败时不会安装。
- 当前阶段只验证未签名预发布链路；正式稳定版必须使用有效的 Windows 代码签名证书。
