## 3. 关键实现与失败行为

### 3.1 报告数据域和初始化

- `full_report` 项目按已绑定模板包初始化报告单例、固定标准、章节和模板块；重复初始化保持幂等。
- `appendix_a` 项目访问报告域 API 时返回 `REPORT_DOMAIN_NOT_AVAILABLE`，不创建隐藏数据。
- 模板包身份、资产指纹或语义 manifest 不匹配时拒绝初始化，不按“当前最新模板”猜测。
- 报告域删除、更新、合并、重排和副作用写入均携带预期 revision；并发冲突不会覆盖已提交数据。

### 3.2 中央对象库与附录 A 适配

- 对象使用稳定 UUID，支持新增、修改、停用、引用保护删除、关系维护、重复候选扫描和显式合并。
- 附录 A 保存由“整节删除重建”改为按稳定行 ID 原位更新；对象绑定、来源行和权威名称投影不会因普通保存丢失。
- 绑定预览只给出 `exact`、`candidate`、`ambiguous`、`unmatched` 建议，必须人工确认后写入。
- 第 3、4 章投影读取附录 A 权威对象名；第 2 章不反向生成或覆盖附录 A。
- A-2/A-4 修正关系只接受真实、同项目、同章节、同指标且与对象绑定一致的原始行引用；R2 不执行修正公式。

### 3.3 章节和结构化块

- 章节树由语义 manifest 初始化，前端不硬编码报告章节清单。
- 七类人工块使用受控 JSON 载荷；非法类型、非法结构、超限载荷、跨项目引用和只读块修改均由后端拒绝。
- 生成章节仅显示只读占位，不接受人工正文。
- `ready_for_review` 会检查所有可编辑表单/块章节完成状态；生成章节、附录 A、附录 B 和只读章节不被错误纳入 R2 完成度阻断。

### 3.4 完整报告工作台

- 新建完整报告项目后可在概览、基础数据、对象库、报告章节和既有附录 A 之间切换。
- 基础信息、单位、成员、阶段日期、分发、系统画像、密码产品、标准和特殊指标使用同一报告 API。
- 页面展示后端返回的结构化错误和 warning；模板批注提示固定为非阻断信息。
- 对象页提供绑定预览、重复合并、对象关系和修正关系入口；章节页提供七类结构化块与完成状态。
- 现有附录 A 项目和 A-1 至 A-8 编辑入口保持兼容。

## 4. 代码审查修正

独立审查发现并已修复以下根因级问题：

1. 附录 A 原“删除后重建”保存策略会使中央对象绑定失效。现改为稳定行原位更新，并增加绑定保持回归测试。
2. 服务层原先先读 revision、后无条件更新，存在竞争窗口。现统一为 SQL 条件更新并检查影响行数，覆盖修改、删除、合并、重排和关联副作用。
3. 块补丁模型与服务读取字段不一致会触发 500。现收敛为单一补丁契约并删除无效模型。
4. 投影曾读取可编辑快照而非附录 A 权威对象名。现统一从权威行读取并在绑定时刷新快照。
5. 修正关系原始引用校验不足。现校验行、项目、章节、指标及对象绑定，缺失或错配返回结构化错误。
6. 对象合并后可能形成包含关系环。现于合并事务内重新校验收缩后的活动关系图。
7. 报告公开字段矩阵原可能带出内部 Ra/Rk 路径。现对公开响应递归脱敏，内部机器矩阵仍保持完整。

修正后重新执行全量检查，未发现剩余的 P1/P2 级阻断问题。
