# 本地运行与打包说明

本文档用于阶段 9 之后的本地验收和交付准备。

## 环境要求

- Windows 10/11。
- Python 3.12。
- Node.js 20 或更新版本。
- 可选：Microsoft Word 或 LibreOffice。安装后可生成 PDF 预览；未安装时，DOCX 导出和结构校验仍可使用，预览任务会显示失败原因。

## 首次安装

后端：

```powershell
cd F:\Codex\FLA\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

前端：

```powershell
cd F:\Codex\FLA\frontend
npm install
```

## 本地启动

后端：

```powershell
cd F:\Codex\FLA\backend
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload
```

前端：

```powershell
cd F:\Codex\FLA\frontend
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173
```

## 完整检查

在仓库根目录运行：

```powershell
.\scripts\run_checks.ps1
```

该脚本会执行：

- 后端单元测试和集成测试。
- Python 编译检查。
- 前端 TypeScript 构建。
- 前端高风险依赖审计。

## 预览渲染器

PDF 预览需要本机具备以下任一渲染器：

- Microsoft Word，并安装可供 Python 调用的 pywin32。
- LibreOffice，且 `soffice` 可被系统找到，或安装在默认路径。

如果没有渲染器：

- DOCX 导出不受影响。
- 校验服务仍会执行 DOCX 结构检查。
- 预览任务会进入 `failed` 状态，并在日志中说明未找到可用渲染器。

## 交付前清单

1. 确认原始样本文档 `F:\Codex\FLA\附录A编写.docx` 未被修改。
2. 运行 `.\scripts\run_checks.ps1`。
3. 确认 `git status --short` 没有临时文件、导出文件、预览文件或缓存文件。
4. 更新 `README.md`、`附录A编写工具实施计划.md` 和 `附录A编写工具开发方案.md`。
5. 提交并推送阶段分支到 `https://github.com/ZN4819/FuLuA`。

## 运行时数据

运行时文件默认存放在：

```text
storage/uploads/
storage/exports/

backend/data/
```

这些文件不应作为阶段开发成果提交到仓库。
